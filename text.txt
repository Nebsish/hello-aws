how image got created:
    1. in my spring boot app , i created a file Dockerfile.    kept all necessary steps.
    2. I did to the project as  mvn clean install:   it will create a jar inside target folder
 ****   3. Then I did a docker build : it reads Dockerfile : which creates the actual image.:
                                                    that image later we have to run for container
       > docker build -t hello-aws:1.4 .
